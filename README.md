# PM-AutoTracker · 项目进度自动化汇总工具

> 一个面向**项目管理实习生**的轻量工具：读取进度表 → 自动算逾期 / 进度偏差 → 生成 Markdown 周报 + 风险清单。
> 零第三方依赖，开箱即用。对应能力：**AI 辅助项目管理中的"自动化报告 + 风险预警"**。

---

## ✨ 为什么做这个

实习时每周人工汇总各模块进度、催办、写周报，约 2 小时且口径易不一致。
我把这套工作拆成三层，再用脚本把"输出层"自动化：

1. **采集层**：各模块提交的结构化进度（CSV / 未来可接 Excel）
2. **逻辑层**：风险判定规则（进度偏差 > 20% 或关键路径延期即标红预警）
3. **输出层**：周报模板 + 风险清单 + 看板

本仓库实现的是第 3 层，并把第 2 层的规则固化下来。

## 🚀 使用方式

```bash
# 默认读取 sample_progress.csv，输出 weekly_report_output.md
python weekly_report.py

# 指定基准日（用于复盘历史周报）
python weekly_report.py --today 2026-10-15

# 指定输入/输出文件
python weekly_report.py --input 我的进度表.csv --output 本周周报.md
```

> 需要 Python 3.8+，无需安装任何第三方库。

## 📋 进度表字段（CSV 表头）

| 字段 | 含义 | 示例 |
|---|---|---|
| `module` | 模块名 | 用户中心重构 |
| `owner` | 负责人 | 张三 |
| `plan_date` | 计划开始日期 | 2026-10-10 |
| `expected_date` | 预计完成日期 | 2026-10-14 |
| `progress_pct` | 当前进度(%) | 70 |
| `status` | 状态 | 进行中 / 已完成 / 未开始 |
| `critical` | 是否关键路径(是/否) | 是 |
| `note` | 备注 | 接口联调延期 |

## 🧠 风险判定逻辑

- **逾期**：`预计完成日期 < 今天` 且 `进度 < 100%`
- **进度落后**：按时间推算"应完成进度"，实际落后超过 `20%` 阈值即预警
- **关键路径**：标记为关键的模块只要未 100% 完成且存在偏差，优先预警

> 说明：脚本负责"罗列异常项"，**人负责判断真伪**——这正是人机协同的关键环节（例如区分"真风险"与"口径差异"）。

## ⚠️ 注意

- 仓库内均为**脱敏后的样例数据**，请勿放入真实公司项目信息。
- 想接真实 Excel？把 `csv` 换成 `pandas.read_excel` 即可（需 `pip install pandas openpyxl`）。
